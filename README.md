# FE1-FF1

Projeto de crossover entre **Fire Emblem 1** e **Final Fantasy 1** (NES), usando os disassemblies da comunidade:

- `fe1/`: baseado em [StanHash/fe1](https://github.com/StanHash/fe1), ajustado para montar a ROM em inglês (v1.4.1). Veja `fe1/NOTAS-CROSSOVER.md`.
- `ff1/`: (em breve) baseado em [Entroper/FF1Disassembly](https://github.com/Entroper/FF1Disassembly).

ROMs não estão no repositório. Para montar o FE1, coloque a sua em `fe1/fe1-base.nes`.
